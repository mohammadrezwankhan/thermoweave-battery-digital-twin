## Scientific risks that remain outside a quick fix

The model has no measured battery calibration or independent high-fidelity comparison. E3's criterion is one predefined pulse scenario; E7 controller comparisons are descriptive, and advanced control can fall back. The SOC integral lacks taper/termination; this is a model boundary as well as a possible input-risk surface. No UI wording, tiny residual or green fixture count converts those limits into validated physical performance. [tools/runExperimentSuite.m:1–227](https://github.com/mohammadrezwankhan/thermoweave-battery-digital-twin/blob/5f29e34788b0f7ee58e2feeafc4df5d48a9a687a/tools/runExperimentSuite.m#L1-L227) [src/+thermoweave/+electrical/socDerivative.m:1–7](https://github.com/mohammadrezwankhan/thermoweave-battery-digital-twin/blob/5f29e34788b0f7ee58e2feeafc4df5d48a9a687a/src/%2Bthermoweave/%2Belectrical/socDerivative.m#L1-L7) [PROJECT_CHARTER.md:1–43](https://github.com/mohammadrezwankhan/thermoweave-battery-digital-twin/blob/5f29e34788b0f7ee58e2feeafc4df5d48a9a687a/PROJECT_CHARTER.md#L1-L43)

The algebraic edge and coolant checks are valuable but do not supply an independent transient oracle. Future tests should hold physical inputs fixed while refining the numerical method, distinguish output sampling from controller timing, and report errors in physically meaningful units. Avoid tests that merely restate the same RHS expression and then call their agreement validation.

## Operational evidence gaps

MATLAB, optional products and supported-browser rendering were not available locally. Classic main protection was inaccessible to the connector, although source check metadata was readable. Independent QA, exact-candidate CI, current policy, legitimate signed integration and deployed-content review remain separate gates owned by the integration/review process. The documentation candidate does not claim them completed.

## Triage protocol

For a defect, record the smallest synthetic config, input/source hashes, source vs runtime status, actual exception/result and expected contract. Reproduce on a clean supported runtime before changing science. For a numerical change, preserve the old fixture, explain compatibility, compare multiple tolerances and update the equation/parameter/API pages plus roadmap status. For documentation-only corrections, validate the scoped diff and regenerate the handbook without refreshing scientific results.

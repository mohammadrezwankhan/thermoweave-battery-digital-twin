## ThermoWeave

[![ThermoWeave thermal field](https://raw.githubusercontent.com/mohammadrezwankhan/thermoweave-battery-digital-twin/main/docs/assets/og.png)](https://github.com/mohammadrezwankhan/thermoweave-battery-digital-twin)

Adaptive spatial electrothermal digital twin for exploring scalar, vectorized, zonal, and coolant-propagation battery boundaries in MATLAB. The portable graph core includes bounded adaptive cooling, seeded fault/variability studies, 31 local tests, and a traceable animated case study.

**MATLAB · graph thermal modeling · numerical verification · accessible data visualization**
